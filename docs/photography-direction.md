# Product & space photography direction

**Status:** the site currently uses programmatic vector illustrations (consistent, on-brand, free). AI image credits in this workspace were limited (10), so photoreal assets were **not** generated. Use the prompts below with any image model (or a real shoot once recipes are tested). Real photos must show *actual tested drinks* — do not publish AI images as photographs of real products without disclosure.

## House style
Warm window light (golden-hour, ~3200 K) from camera-left, soft bounce right; seamless oak/terracotta/plaster surfaces; one hero drink, one supporting prop (honey dipper, cinnamon, petals); shallow depth of field (f/2.8); 4:5 for feed/website, 9:16 for TikTok/Reels, 2:3 for Pinterest; negative space for text; palette limited to Espresso/Crema/Aurum/Ember/Cardamom.
Avoid: stock-photo smiles, harsh flash, blue-white light, plastic-looking foam, floating ingredients, over-saturation, visible third-party logos.

## Prompt template
> Premium commercial beverage photograph of **[DRINK + vessel]**, **[garnish]**, on **[surface]** against a **[brand-colour backdrop]**, low golden-hour window light from the left, soft shadows, shallow depth of field, realistic condensation/foam texture, editorial advertising composition with space on the right, 4:5, no text, no logos.

## Space renders (consistent set — reuse these anchors in every prompt)
Anchors: *arched steel-framed windows, lime-plaster walls, oak counter with charcoal base, brass pendant lights (2700 K), terracotta banquette, cardamom-green plants, charcoal fascia with monoline "AUREVO" logotype whose O is a sun.*
1. Exterior daytime · 2. Exterior night (amber glow through arches) · 3. Interior wide (counter + shelving) · 4. Coffee counter (machine facing guests) · 5. Seating (banquette, window light) · 6. Product-photography corner.
Generate all six in one session with the same seed/style reference to keep them consistent.
