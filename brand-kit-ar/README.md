# دليل العلامة التجارية والامتياز (النسخة العربية)

| الملف | الوصف |
|---|---|
| `<name>-brand-franchise-kit-ar.pdf` | **الدليل الرئيسي** (80 صفحة): فكرة العلامة، الهوية البصرية، الأكواب والتغليف، تصميم المحل، المنيو بأسلوب القوائم، كل الوصفات (14 مميزاً + 27 كلاسيكياً)، دليل التشغيل، الامتياز والميزانية، الجانب القانوني |
| `<name>-menu-costing-ar.xlsx` | جدول التكاليف بالعربي بمعادلات حيّة، مع ورقتي **سجل الاختبار** (3 تجارب لكل صنف) و**حالة الاعتماد** (تظهر تلقائياً «جاهزة للاعتماد») |
| `photo-prompts.md` | أوامر جاهزة لتوليد صور مؤقتة لـ 14 مشروباً (للعرض الداخلي فقط، موسومة «تصوّر بالذكاء الاصطناعي») + قائمة التصوير الحقيقي |
| `assets/` | كل التصاميم SVG بنصوص عربية (تحتاج خط Cairo مثبتاً لعرض النص صحيحاً) |
| `assets-png/` | نسخ PNG جاهزة للاستخدام (الخط مدمج) |
| `data/` | `menu-ar.json` |

## تغيير الاسم
```bash
BRAND_NAME="Your Name" AR_DESCRIPTOR="وصف قصير" AR_SLOGAN="شعارك" npm run kit:ar
```
الشعار بالحروف الإنجليزية فقط (A–Z). النصوص الوصفية عن «الساعة الذهبية» في `scripts/build-kit-ar.mjs` وتُعدَّل لتناسب قصة اسمك.

## الوضع الحقيقي
مرحلة المفهوم: الوصفات **مقترحة ولم تُجرَّب**، التكاليف والأسعار والأرباح **تقديرات**، أبعاد الأكواب تقريبية، المخططات توضيحية، الاسم **غير مفحوص** كعلامة تجارية، ولا يوجد عقد امتياز.
